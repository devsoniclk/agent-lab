# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We prioritize the security and cryptographic integrity of `agent-lab`.

If you discover a security vulnerability or exploit in the sandbox execution, consensus engine, or cryptographic attestation modules:

1. **Do not create a public issue.**
2. Send an advisory report via private GitHub Security Advisories at [devsoniclk/agent-lab/security](https://github.com/devsoniclk/agent-lab/security).
3. Include detailed steps to reproduce, sample proof-of-concept code, and the affected version.

Reports receive triage within 24 hours and patches within 72 hours.
