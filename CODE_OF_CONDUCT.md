# Code of Conduct

The `agent-lab` project is dedicated to providing a respectful, harassment-free, and productive environment for all contributors, maintainers, and users.

## Standards

- Treat every participant with courtesy, dignity, and professionalism.
- Focus on constructive technical discussion and evidence-driven engineering.
- Provide thoughtful, empathetic feedback during code reviews and issue triage.

## Enforcement

Violations of community standards may be reported to the project maintainers via GitHub. Maintainers reserve the right to moderate, edit, or close contributions that violate these standards.
